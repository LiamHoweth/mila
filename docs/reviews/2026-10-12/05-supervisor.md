# 05 — Supervisor logic review

**Verdict: PROTOTYPE FIRST, isolated simulator only.** The settled logic implements inhibition and manual rearm coherently; no confirmed static misconnection emerged. Physical timing, pulse recognition and firmware semantics remain unproved. Confidence: high for connectivity; moderate for the conditional counterexamples below; no physical result.

**CONFIRMED SOURCE:** Fresh read-only XML inspection found `/HEALTH_N` joining U1-8/U2-1/U3-1/R5/U4; `/QUALIFIED` joins U9-4, both U10 clears, U11-1 and U13-2; `/HB_CLK` drives both U10 clocks; `/ARM_D` joins U12-4/U11-2. Generator lines 73–130 match these exported nets. SET0/SET1=LOW and CWD/CRST 10 kΩ pullups match the stated watchdog configuration. R3/R4=100 kΩ are within TI's 40–200 kΩ CT recommendation. Sources checked October 12, 2026.

Ranked findings:

1. **Valid heartbeat with invalid output defeats this supervision.** Trigger: firmware continues READY and correctly timed WDI while DAC data/command freshness is wrong. Consequence: U10/U11/U13 retain permission indefinitely; there is no independent analog or command monitor. Evidence: generator U8/U12/U13; README lines 117–123; model `wdi_falling_edge()` explicitly separates timing from semantics. **CONFIRMED SOURCE.** Require a guarded control iteration and measured simulator outputs; label independent plausibility as absent.

2. **Heartbeat counting and watchdog pulse acceptance are different.** Trigger: marginal amplitude or narrow WDI pulses accepted by U6/U10 but not guaranteed accepted by U1. Consequence: HB_GOOD can assert before the late watchdog timeout, potentially allowing transient ARM acceptance. `/WDI` directly feeds U1-7 and U6-1; U10 counts U6 edges without a watchdog acknowledgment. U1 requires HIGH ≥0.8×VDD, LOW ≤0.3×VDD and ≥50 ns pulses; R14/R10 also reduce the header HIGH. **ANALYTICAL INFERENCE**, not an observed defect. Specify and measure these levels at U1, separately from the request-net 2.60 V criterion; scope HB_GOOD/WDO during amplitude/pulse-width sweeps. [TPS3430-Q1 §§6.5–6.6, pp.6–7](https://www.ti.com/lit/ds/symlink/tps3430-q1.pdf).

3. **Short clear pulses can preserve delayed heartbeat data.** Trigger: QUALIFIED drops long enough to clear U10 but recovers before R24/C18/U14 flush, followed immediately by WDI. Consequence: the first post-fault edge can sample stale HB_ONE_SAFE=HIGH, defeating unconditional two-edge qualification. Evidence: generator lines 124–130, 176/186; README lines 101–107 already constrains LOW ≥10 µs and post-recovery edges ≥1 ms. **ANALYTICAL INFERENCE outside that valid protocol.** Preserve these requirements and test S18; do not claim arbitrary fault pulses are covered.

4. **ARM/request and clear/clock coincidences remain asynchronous.** Trigger: request or QUALIFIED transitions around ARM/WDI. Consequence: setup/recovery violation or metastable/transient permission is possible. U11 samples U12 directly; clear release is unsynchronized. LVC74A specifies data setup 3 ns, hold 1 ns, clear-inactive setup 2 ns and pulse width 3.3 ns. **UNKNOWN physical response.** Phase-sweep S17 with coil current, not Boolean output alone. [LVC74A-Q1 §§4.6–4.7, p.5](https://www.ti.com/lit/ds/symlink/sn74lvc74a-q1.pdf).

5. **Fault response has no application limit.** Trigger: missing WDI or brief returned-5 V interruption. Consequence: late detection may approach 125.4 ms plus downstream release; short rail transients may escape U3/C17. This cannot establish acceptable transfer behavior. [TPS3808-Q1 §7.6, p.6; §8.3.4, p.11](https://www.ti.com/lit/ds/symlink/tps3808-q1.pdf). **UNKNOWN required limits.**
