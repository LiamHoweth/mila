# 07 — Analog and DAC independent review

2026-10-12. **Verdict: PROTOTYPE FIRST, isolated signal fixture only.** Compact Form-C selection addresses settled connectivity, but analog validity during selection and transfer is unproved. No vehicle integration. Confidence: high in source observations; low in application adequacy.

## Ranked findings

1. **Stale output can coexist with permission.** Trigger: I²C/DAC failure while MCU-generated READY and heartbeat remain valid. Consequence: indefinitely selected wrong/held voltage, rather than automatic bypass. CONFIRMED SOURCE: `docs/passive-bypass-design.md:222–240` says READY is external and PG5 senses returned carrier input, not independently measured DAC outputs. Reference `/Users/howeth/Downloads/FabriceBoard_PID_AutoSweep(1).ino:111–135,204–207` ignores write results and retains startup `dac*_ok`. Current [Adafruit implementation](https://raw.githubusercontent.com/adafruit/Adafruit_MCP4728/master/Adafruit_MCP4728.cpp) returns write failure; the sketch's installed library version is UNKNOWN. PROPOSED CHANGE: fail closed on each transaction failure, command-age violation and measured output mismatch; service WDI only after a completed valid cycle. Correlation alone cannot establish correct command intent.

2. **DAC loss can precede contact return, and separate DAC loss need not trip PG5.** Trigger: abrupt DAC-only collapse or falling common supply. Consequence: dead/invalid source remains selected until detection plus coil decay/release/bounce; if READY remains high on DAC-only loss, there may be no automatic cutoff. CONFIRMED SOURCE: `docs/passive-bypass-fmea.md:84–96`; validation V05/V08 remain NOT_RUN. ANALYTICAL INFERENCE: a coil-feed monitor cannot directly diagnose a separately powered DAC. Measure DAC VDD, two selected COMs, coil current, READY and permission simultaneously; repeat fast removal and slow ramps at several codes. Do not call final NC restoration uninterrupted continuity.

3. **Cold-start and reset outputs are history-dependent.** Trigger: DAC powers before controller initialization or receives reset. Consequence: EEPROM codes/configuration appear before firmware's requested values. [Microchip DS22187E](https://ww1.microchip.com/downloads/en/DeviceDoc/22187E.pdf), §§4.0–4.2 p23, confirms automatic EEPROM recall. §3.5 p22 identifies RDY/BSY as EEPROM programming status: it is not the supervisor's semantic READY. PROPOSED CHANGE: record EEPROM and volatile state, keep contacts in bypass, set/read configurations and externally measure actual outputs before READY. Test controller reset with DAC powered and DAC reset with controller powered.

4. **1 mV nominal resolution does not establish absolute or ratiometric accuracy.** Trigger: treating `VFS=4.096` and internal-reference/gain-2 settings (`.ino:79–85,111–115`) as calibrated sensor equivalents. Consequence: systematic voltage/correlation error or reference-offset error. Microchip pp4–5 specifies internal reference 2.007–2.089 V, offset up to 20 mV and conditional gain/nonlinearity limits. ANALYTICAL INFERENCE: an internally referenced absolute voltage does not follow an ECU sensor reference unless deliberately measured/controlled. Endpoint reference, loading, accepted pair function and bandwidth are UNKNOWN. Measure transfer curves versus rail, load and reference offset; derive an error budget from identified endpoint limits.

5. **Sequential updates and physical pair skew require waveform evidence.** Trigger: complementary A/B writes or DPDT transfer. Consequence: temporary mixed command/source pair. `.ino:131–134` writes sequentially; current library defaults immediate updates. Microchip §3.4 p22 supports staged LDAC updates, but actual module LDAC wiring is UNKNOWN. Proposed synchronized updates cannot eliminate relay pole skew. Scope both pair outputs through normal changes and injected failures.

6. **Fixture attenuation can masquerade as path error.** CONFIRMED SOURCE: carrier `pin_net_map.csv:3–8,20–25,37–39,54–56,102–105` identifies four alternate paths and cross-connected K7/K8 sources. `docs/passive-bypass-design.md:47–52` correctly predicts 4.545 V for one load and 4.167 V for two at 5 V. Measure resistor values, probe loading and source voltages; compute expected attenuation before grading contacts. This fixture cannot establish vehicle impedance compatibility.

## Stop criteria

Stop on unidentified terminals, source-fault current above 1 mA, unexplained selection, spontaneous rearm or unexpected rail injection. Do not advance beyond screening until measured mismatch/transfer duration is compared with independently established endpoint allowances. Reject analog substitution if acceptable correlated behavior, reference topology or fault response cannot be defined. No physical result is claimed.
