# 14 — FMEA and fault coverage

2026-10-12; independent first analysis. **Verdict: PROTOTYPE FIRST**, only an isolated, current-limited simulator investigation. Vehicle integration: **NO**. Existing FMEA is appropriately narrow; adding a watchdog does not make contact transfer redundant or prove a vehicle safe state. No physical result is claimed here.

## Ranked findings

1. **Automatic cutoff has several single-fault defeats. CONFIRMED SOURCE / ANALYTICAL INFERENCE.** Carrier Q5 drain-source short directly joins `5V_RAW` to `COIL_5V`; Q6 drain-source short pulls `P_GATE` to ground, enabling healthy Q5 despite withdrawn permission. Supervisor U13 stuck HIGH has the same authority consequence while requests remain asserted. These are distinct faults on one automatic release chain, not independent automatic channels. Physical series enable can still cut the intended feed, but requires operator release and intact wiring. Evidence: carrier `pin_net_map.csv:70–89`; supervisor `pin_net.csv:93–97`; `tests/test_passive_bypass_model.py:141–174`. The FMEA names Q5 and generic logic faults but should explicitly distinguish Q6 from individual coil drivers. [AOS AO3400A](https://www.aosmd.com/sites/default/files/res/datasheets/AO3400A.pdf), [AO3401A](https://www.aosmd.com/sites/default/files/res/datasheets/AO3401A.pdf), p.1 pinout/polarity.

2. **Zero-request ARM cannot prove zero coil current. CONFIRMED SOURCE.** Short Q1 drain-source with every request LOW: qualification and ARM can succeed, then energize RLY1 unexpectedly, switching K3/K4 without K5/K6. ZERO_REQ measures command nets, not driver health/contact position. The existing test explicitly exposes this: `tests/test_passive_bypass_model.py:176–183`; carrier pin map Q1; supervisor U7/U12. Proposed improvement is a named pre-arm physical driver/coil check in the fixture; independent feedback is a later design requirement only if automatic fault tolerance becomes required.

3. **Removing coil energy cannot repair the signal path. CONFIRMED SOURCE.** NO weld/stuck mechanism retains selection; NC/COM/trace/harness open loses bypass; a BOTH fault joins sources. DPDT RLY1/RLY2 place two channels on each common mechanism, so six poles are not six independent mechanisms. Model faults are per-pole abstractions, not failure-rate or common-cause coverage. Evidence: `passive_bypass_model.py:24–35,51–56,228–229`; FMEA contact rows; validation V21. K7/K8 cross-coupling can propagate source shorts; “exact_default_connections” establishes connectivity only, not safe endpoint response.

4. **Valid heartbeat/READY can mask dangerous output indefinitely. CONFIRMED SOURCE.** A stalled command producer with surviving heartbeat, wrong-but-correlated DAC codes, or READY stuck HIGH does not necessarily trip. No independent DAC/contact readback appears in supervisor pin nets. Evidence: model module contract; supervisor J1/U8; FMEA READY/stale-command rows. Timing supervision cannot establish command freshness, intention, bounds or successful physical output update.

5. **Recognized-fault rearm differs from every reconnection. CONFIRMED SOURCE.** Individual request/permit/coil-branch interruption and brief undetected bundle chatter can restore energized state under retained ARM. Returned PG5 senses carrier input before Q5, not downstream continuity. Shared ground loss/backfeed can defeat assumptions without becoming a clean Boolean fault. Evidence: carrier JCTRL1-6; supervisor J5-7/R22; model `coil_commands`; validation V13,V31,V32. This is already disclosed; do not broaden the recovery claim.

## Decisive measurements and stop criteria

Use ≤1 mA simulated signal paths; record COM voltages, source currents, Q5 gate, coil current, HEALTH/ARM. Extend V20 with separate Q6-short and stuck-permission cases, plus Q1-short **before** zero-request ARM. Exercise V21/V32 and valid heartbeat with deliberately stale outputs. Record detector-to-stable-NC delay, wrong/open-output exposure and whether recovery needs fresh ARM; compare with explicit provisional bench limits, never invented vehicle limits.

Stop for current-limit violations, unexplained actuation, missing physical-feed authority or mismatch from documented topology. Kill/pivot if later requirements demand automatic recovery from welded/open contacts or every single-fault cutoff using this unchanged architecture. Actual endpoint safe states, fault-response limits and diagnostic coverage remain UNKNOWN; all physical matrix entries remain NOT_RUN.
